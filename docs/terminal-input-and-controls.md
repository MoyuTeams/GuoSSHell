# 终端输入、缩放与功能按钮

## 硬件修饰键

App 使用 Flutter 的原生硬件按键和输入法路径，终端编码由已有引擎处理，不注入额外的全局修饰键状态。
真机验收同时核对 Ctrl / Option / Shift / Command 组合，以及松开修饰键后的普通文字。
输入链路缺失释放事件时的环境问题记录在 [修饰键事件跟进](followups/20260926_真机修饰键输入异常.md)。

源码参考范围：SwiftTerm 按每次 `UIPress` 的修饰位处理硬件组合并在释放/取消时结束对应按键；
iSH 通过 `UIKeyCommand` 注册终端组合；Blink 使用 WebKit 输入并单独处理原生快捷键与修饰键变化。
本项目保留现有 Flutter / Rust 输入架构，不引入第二套终端解析器。

- [SwiftTerm iOS 输入实现](https://github.com/migueldeicaza/SwiftTerm/blob/aec009a2a535db369b7b3d534b198788b7e11932/Sources/SwiftTerm/iOS/iOSTerminalView.swift)
- [iSH 硬件组合键](https://github.com/ish-app/ish/blob/83348361fe65311f6e87ad2e1cbb0ac38d123f69/app/TerminalView.m)

## 缩放

- 在终端画面用两指捏合或展开；触控板捏合也支持。
- Apple 平台使用 `⌘+` / `⌘=`、`⌘−`、`⌘0`；Windows 使用 `Ctrl` 对应组合。分别用于放大、缩小和恢复默认字号，也支持数字键盘。
- 仅调整当前窗格，范围为设置允许的字号上下限。重置回到该窗格打开时的默认字号。
- 缩放更新字体度量与终端行列，并经现有尺寸变化通道通知远端，不向 SSH 发送缩放快捷键。
- 单指滚动、触控板双指平移仍用于滚动。默认字号仍在设置页配置，缩放不覆盖它。

## 自定义功能按钮

从终端下方的“编辑功能按钮”图标或设置页进入编辑器：

- 编辑器直接显示两排按钮预览，与终端共用尺寸和排布；拖动按钮即可排序或移到另一排。
- 从按钮目录拖入指定位置，或点击目录按钮加入当前排；拖到删除区移除，也可选中后点击删除。
- 支持“空位”按钮；拖到空列时保留列位置，可自行对齐方向键与其他按钮。
- 所有按钮等宽、无边框与圆角；文字区域最多两个汉字宽，较长名称缩写或截短，指针悬停可查看全名。
- 默认方向键呈倒 T 形：↑ 在 ↓ 正上方，← / ↓ / → 相邻。窄屏两排一起横向滚动，不自动换行。
- 每排最多 24 个位置（含空位），允许留空；编辑入口始终保留。
- 可添加普通终端键、方向键、F1–F12、常用 Ctrl 组合、复制粘贴、键盘开关和缩放动作。
- 可添加最多 32 个字符的自定义文本按钮；点击输入文本，不自动发送回车。
- “恢复默认”修改当前草稿；“保存”成功后立即应用，退出编辑器则放弃未保存的草稿。

排布保存在本机偏好文件中，与字体、滚回和钥匙串同步开关分别更新。
旧配置没有排布字段时使用默认值；空排与未配置分开保存。
旧版本的原始默认排布自动升级为方向键对齐的布局，已有自定义排布保留。
进入编辑器会停止键位条自动重复并解除其挂住的修饰键，避免移除按钮后继续发送旧组合。
