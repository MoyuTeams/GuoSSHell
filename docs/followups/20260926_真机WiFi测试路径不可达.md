# 真机 Wi-Fi 测试路径不可达

## 问题

真机经 Wi-Fi 访问局域网验收服务器时，SSH 连接超时，HTTP 连接返回主机不可达。
设备与 Mac 的接口地址处于同一网段，但 Mac 未收到设备的邻居发现回应。
这条路径尚不能用于 Wi-Fi 端到端性能验收。

## 现状

配对、开发者信任、签名安装和调试服务均可用；原生网络诊断确认路径授权已允许。
Mac 系统防火墙未开启，测试服务器在本机可访问。
经已配对设备的 USB 网络通道，SSH 响应与 HTTP 接口均验证通过，可以继续功能与渲染性能验收。
尚无证据指向 SSH 认证或终端渲染，也不能把 Wi-Fi 故障直接归因于某一项权限或路由器设置。

## 下一步

检查两端实际接入的网络、设备隔离和邻居发现，恢复 Wi-Fi 互访后补跑真实无线链路的连接与延迟测试。
