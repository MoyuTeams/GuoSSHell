# Windows 本地故障 fixture 退出码

## 问题与当前边界

桌面 CI 的 `fault_unwind` 子 fixture 曾返回 `0xC000013A`，不符合受控故障清理完成后退出码为 `1` 的契约；外层监督测试因此失败。当前本地 GNU 与 MSVC 定向运行均满足退出码、非强杀和资源清理断言，但未复现该远程退出码，尚不能确认远程失败根因或宣称 CI 已修复。

预期展开使用类型化 payload，必须完成原 owner 的真实清理。测试继续要求退出码为 `1`、监督结果成功、没有强制终止，以及最后持有者释放后退款；不得接受任意退出码或扩大进程终止权限来取得通过。

## 下一步

在对应 Windows CI 路径核对故障注入、子进程终止及等待的实际结果，区分 fixture 的退出语义与产品清理行为。若仍失败，保留精确进程身份与资源证据进行定向复现，再按最小边界修正；其他平台和完整 Local Shell 验收仍须实际运行证据。
