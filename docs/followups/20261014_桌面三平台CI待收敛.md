# 桌面三平台 CI 待收敛

## 问题与现状

[桌面验证作业](../desktop-validation-ci.md)在三平台运行 Cargo fmt/check/clippy/test、Flutter analyze/test 与 debug 构建。`hub` 的实验候选测试已由 `experimental-candidates` feature 移出默认测试集，在独立的 `continue-on-error` 步骤运行，不计入门禁。

当前三平台是否全绿，以对应提交的实时作业结果为准；被跳过或未执行的步骤不能记为通过。本地 Windows 的 Flutter 全套与 Rust workspace 测试通过，不能替代三平台 CI。CI 不执行原生 GUI smoke、真实 PTY/系统 ssh 测试或 macOS 沙箱内运行，构建成功不等于原生运行验收。

## 下一步

对每个新提交读取实时作业，若有失败则定位首个实际失败，区分功能回归、平台差异与并行共享状态；不以忽略测试、串行整个套件或放宽断言收敛结果。实验候选步骤的固定临时目录等前件见[实验候选测试依赖固定临时子目录](20261014_实验候选测试依赖固定临时子目录.md)与[helper 产物前件](20261014_Rust全套测试的helper产物前件.md)。
