# 焦点上报（DECSET 1004）不发送

- 状态：待修
- 记录日期：2026-09-26

## 问题

远端开启焦点上报（DECSET 1004）后，终端应在获得 / 失去焦点时发送 `CSI I` / `CSI O`。App 从不发送：

- Codex 靠它决定是否发桌面通知（只在失去焦点时通知）、何时做自动摘要；
- vim、tmux 等用它在切回时刷新文件状态、切换光标形状。

远端收不到焦点变化，就一直当作「有焦点」。

## 现状

- 引擎记下了远端是否开启 1004，但上游 rsHell 的显示模式没有暴露它，也没有发送焦点序列的入口；
  hub 与 Dart 都不发送。

## 下一步

1. rsHell 补丁：`TerminalDisplayModes` 暴露焦点上报模式（与 bracketed paste 的 P1 同一处）。
2. hub 在窗格焦点变化、App 进后台 / 回前台时，按该模式发送 `CSI I` / `CSI O`；
   决定「App 进后台」是否等同失去焦点（建议等同）。
