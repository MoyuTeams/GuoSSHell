# 分支后深层安全加固风险

## 范围与评级

本分支保障应用、界面及平台宿主可控的安全与可靠性。需要深改密码学、压缩、分配器或系统同步实现的高保证加固，延至本分支之后；它们不再是桌面功能交付前件。本文记录剩余风险，不代表已发现可利用漏洞，也不签发完整资源或密码学证书。

评级综合影响、攻击前提和应用侧缓解能力：高风险指已确认的认证绕过、凭据泄漏、内存不安全或不可控破坏，不能仅记账延期；中风险指有条件的保密性或可用性风险，须保留应用侧缓解；低风险指未发现功能缺陷的证明或故障覆盖缺口。没有足够数据时不编造 CVSS 分数。

| 延期项 | 风险等级与前提 | 当前边界 | 本分支缓解 | 分支后下一步 |
|---|---|---|---|---|
| HMAC、SHA、ring 等内部秘密副本和 scratch 的完整擦除 | 中：秘密泄露影响高，但通常需要内存读取、转储或同等本地访问能力；不是已确认的远端泄密 | 应用不能通过公开 API 访问所有派生块、摘要、克隆及原生临时状态；启用清理 feature 不等于覆盖全部副本 | 不记录或持久化明文凭据；控制应用自持副本与生命周期，使用既有可信密码学实现及可用清理能力，不自写或削弱算法 | 定向审计实际后端，仅为确证的不可达清理点增加最小依赖接缝，并验证失败、取消与析构 |
| 全部可达分配的调用前源式准入和全进程硬包络 | 中：极端配置、字体或远端流量可能产生内存压力；尚未证明严格全量上界 | 原 P1 的 `403701760` 与 `SourceClosed` 全量证书未完成，不能宣称覆盖第三方 heap、系统资源或整个进程 | 对应用自持的大对象、准备态、队列和并发实施预算、背压、超时与取消；不截断配置、不拒绝正常小配置；实际崩溃或可控耗尽仍须修复 | 独立完成跨库源图、真实 owner、目标布局与最后释放证书；不能用峰值测量代替硬保证 |

## 本分支不能延期的保证

- host-key 校验与变化处理、认证信任边界、应用凭据保护及必要沙箱权限保持。
- System OpenSSH 在本地终端中运行用户自己的 `ssh`，使用其配置、agent 与 known_hosts，主机密钥与认证在终端内交互；应用不读取或转存这些凭据，密码、私钥内容不进入命令行、环境或报告。
- 实际使用路径上的 UAF、指针别名、持根环、提前释放、错误竞态、死锁和 keepalive 语义缺陷必须修复，不能归入高保证延期。
- 配置事务、不可变会话快照、旧接口兼容、正常压缩及三平台功能验收仍须完成。未运行的 GUI／沙箱／硬件场景如实标注。
- 候选代码保留但不自动进入正式依赖或生产入口；不能直接删除 V2 守护来替代生产接线和功能验收。

## 候选与维护入口

已发布库候选与未整合实验代码不作为本分支依赖升级的理由；来源、实际 pin 和补丁身份仅维护在根 `UPSTREAM.md`。具体问题见 RNG、scoped 压缩、macOS 冷锁及真实系统熵错误条目。本分支之后按风险和实际可利用性安排加固，不承诺本分支完成全量秘密擦除、严格全资源包络或整体编译后常时性证明。
