# 实验候选测试依赖固定临时子目录

## 问题

`experimental-candidates` 门控下的部分 hub 集成测试（`selected_p1_font_provider`、
`selected_p1_helper_runtime`、`selected_p1_helper_artifact`）要求系统临时目录下预先
存在一个固定名称的子目录，不存在时在 fixture 初始化处断言失败。干净的开发机与 CI
runner 上该目录通常不存在。

## 现状

这些测试不在默认 `cargo test --workspace` 中；CI 以 `continue-on-error` 和
`--no-fail-fast` 单独运行并把结果写入作业摘要，不计入桌面功能门禁。本机运行时
`selected_p1_font_provider` 有 15 项因此失败。

## 下一步

改为在系统临时目录下由 fixture 自行独占创建本次目录并精确清理，不依赖外部预置目录；
随实验候选的后续整理一并处理。
