# 真机短场景卡顿与空闲回显超标

## 问题

真机 profile 构建、关闭截图的独立性能轮中，按现有总帧耗时口径计算，部分短场景超过 1% 的卡顿帧门槛：

| 场景 | 卡顿帧 / 总帧 | 比例 |
|---|---|---|
| Claude Code stream | 4 / 169 | 2.37% |
| Claude Code burst | 2 / 104 | 1.92% |
| Claude Code cjk | 3 / 122 | 2.46% |
| Claude Code inline-cjk | 6 / 131 | 4.58% |
| opencode inline-cjk | 2 / 190 | 1.05% |

空闲 shell 回显的 12 个样本中有一个为 218 ms，其余为 17–19 ms，按当前采样与百分位算法计算的 p95
因此超过 50 ms。另一窗格高速输出时，回显 p95 为 18 ms。

## 现状

功能断言、画面一致性、退出后模式恢复均通过；显示延迟、ACK 超时和长会话内存增长达到对应门槛。
此轮没有调用截图接口，故上述卡顿与回显异常不能仅归因于测试插件保留截图。
测试使用已配对设备的 USB 网络通道，不代表 Wi-Fi 链路性能。

## 下一步

对超标场景采集 build、raster、vsync 与 GC 的时间分布，区分字体或布局冷启动、输入法和帧调度开销。
扩大空闲回显样本，并单独记录首个输入与稳定输入；保留现有门槛，复验后再决定是否需要修改运行路径。
