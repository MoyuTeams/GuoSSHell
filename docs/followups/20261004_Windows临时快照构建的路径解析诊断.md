# Windows 临时快照构建的路径解析诊断

## 问题

Windows 临时快照使用短路径构建时，`rinf/cargokit/cmake/resolve_symlinks.ps1`
的 `Get-Item` 输出无法找到路径项的诊断，相关输出还存在中文乱码。
目前尚未确认短路径、符号链接及编码各自的影响。

## 现状

诊断未阻断该快照的 Windows debug 构建及原生字体协议测试，两者均成功结束。
尚无证据证明路径解析失败在其他构建位置也不影响结果，不能将成功构建视为诊断已解决。

## 下一步

在受控目录建立最小复现，分别检查短路径、符号链接和编码，确认构建是否依赖回退路径。
优先在应用构建配置侧解决；确需上游变更时，按上游依赖规则评估必要性并统一记录。
