# 主机密钥按解析后的 IP 记录

- 状态：待办（非阻塞）
- 记录日期：2026-09-25

## 现状

上游原生 SSH 传输用 TCP 连上后的对端 IP 与端口校验、记录主机密钥（known_hosts 里是
`[IP]:端口`），不记主机名。于是：

- 同一主机名换了 IP（DHCP、DNS 变更）会被当成「新主机」再问一次，而不是沿用已信任的密钥；
- DNS 被劫持指向另一台机器时，看到的是「首次连接」提示而不是「密钥已变更」警告，
  比 OpenSSH（主机名与 IP 都查，`CheckHostIP`）弱；
- 确认对话框里的主机名是用户填的，括注的才是 known_hosts 实际记录的地址。

## 下一步

改上游（fork 补丁）：校验时同时查主机名与 IP——主机名条目优先，主机名已知而 IP 变了只更新
IP 条目；主机名条目的密钥不一致才算变更。需要改 `StrictClientHandler` 传入的主机与
`KnownHostsVerifier` 的查找顺序。
