# 桌面原生输入窗口方案搁置

## 现状

桌面终端输入已统一走 Flutter 按键、文本与鼠标事件经有序通道交 Rust，由 Rust 按会话 profile 匹配绑定、左右 Alt 并编码；渲染库（`terminal_view` 团队 fork）提供按键来源与左右 Alt。该路径的已知缺口见[桌面 V2 输入剩余缺口](20261014_桌面V2输入剩余缺口.md)。

另一条方案——Windows 私有原生输入窗口（NativePort、`desktop_native_host`、`desktop_session_controller`、`windows/runner/desktop_native_input`），由原生层在 Translate 前与 TSF 前取得同源事件——代码保留，但不接线、不开放，也不在本分支验收。

## 下一步

仅当上述缺口无法在 Flutter 路径内解决（如 Windows 上 AltGr/IME 与按键同源仲裁），才重新评估该方案；届时须先证明线程与队列边界、焦点与 generation 终结、迟到文本拒绝，并保持不采集认证字段与其他窗口、不启用全局键盘监听。
