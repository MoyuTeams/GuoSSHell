# macOS 沙箱下本地进程能力边界

## 问题

macOS Debug/Profile 与 Release 宿主均启用 App Sandbox。System OpenSSH 的能力查询只检查
PATH 中是否存在 ssh，本地 shell 只检查是否为桌面平台；这不足以证明子进程能够访问用户的
SSH 配置、known_hosts、私钥、agent、主目录及 shell 启动文件。

## 现状

应用保持沙箱，不额外授予用户目录或 agent 权限。沙箱内真实运行与用户资源访问尚未完成验证，
不能把编译成功或 PATH 检测当成完整本地终端／System OpenSSH 能力证据。

## 下一步

确认受限宿主的产品能力范围：暂时报告本地进程能力不可用，或设计显式授权的资源访问边界。
选择后统一能力查询与启动入口，并在真实签名沙箱构建中验证允许和拒绝场景；不得以关闭沙箱
或自动信任主机密钥代替修复。
