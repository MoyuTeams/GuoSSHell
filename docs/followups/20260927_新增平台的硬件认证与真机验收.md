# 新增平台的硬件认证与真机验收

## 问题

Android、Windows、Linux 已有应用宿主和受保护的凭证存储，但 OpenPGP 卡与 FIDO2
系统交互仍使用不可用后端。这些平台尚无与 Apple 真机同等覆盖的硬件键鼠与生命周期验收。

## 现状

CI 覆盖多架构应用编译、Rust 与 Flutter 回归。Android 使用 Keystore，Linux 使用
Secret Service，Windows 长私钥使用 DPAPI。现有 Apple 硬件认证后端保持可用，其他
平台不宣称具备对应硬件能力。

## 下一步

选择并接入各平台可复用的智能卡及安全密钥后端；补充真实设备上的键盘、中文输入法、
后台恢复、凭证持久化及升级安装验收，按平台记录可用范围。
