# 原生输入原型 SDK 的 ABI 预检过时

## 问题

原生输入原型 SDK 的 Dart 预检（`lib/src/desktop/native_input_spike_sdk/protocol.dart`）
仍要求 `coreAbi == 2`、`coreExports == 8`，而原生核心与共享头已是 ABI 3、11 个导出
（`windows/runner/native_input_spike_sdk/real_abi_test.cpp` 按此断言）。Rust 侧 SDK
（`native/hub/src/native_input_spike_sdk/mod.rs`）回应的 `CORE_ABI` 也仍为旧值 2。
两端握手契约不一致，显式启用的 spike SDK fixture 会在 bootstrap 预检阶段被拒绝。

## 现状

原生输入原型已搁置、不接线。该问题只影响显式启用的实验验证入口（spike SDK fixture
及对应集成测试），不影响正常桌面终端，也不在默认 CI 路径上。

## 下一步

若恢复原型：统一 Dart 预检、Rust SDK 与原生核心的握手契约（ABI 版本与导出数取同一来源），
并补一条用真实宿主诊断走完 Dart bootstrap 的验证，避免契约再次单边漂移。
