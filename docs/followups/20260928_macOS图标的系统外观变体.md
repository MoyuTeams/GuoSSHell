# macOS 图标的系统外观变体

## 问题

macOS 的资源目录图标（AppIcon）不支持外观变体，应用图标不随系统深色模式切换。
macOS 26 起，自定义的深色、透明与着色外观需要 Icon Composer 的 `.icon` 文件；
资源目录图标在这些版本上按旧版图标显示。iOS / iPadOS 26 的液体玻璃效果同样需要 `.icon`。

## 现状

macOS 使用暗色版源图生成的圆角方块图标，按 Apple 旧版图标模板的网格绘制，覆盖 macOS 12 起的全部版本。
iOS / iPadOS 由资源目录提供亮色与暗色两版。CI 的 Apple 构建已使用支持 `.icon` 的 Xcode 26。

## 下一步

用 Icon Composer 以 `assets/icon/` 的源图分层制作 `.icon`（背景随外观切换亮暗），加入 iOS 与 macOS 的
Runner 工程，并决定两个平台共用一个 `.icon`，还是按旧系统回退图标的亮暗分别制作。在 26 起的系统与旧系统
（iOS 15–18、macOS 12–15）上分别核对主屏幕、Dock、访达与启动台中的显示，以及回退图标。
