# OSC 52 复制进不了系统剪贴板

- 状态：待决定（产品）
- 记录日期：2026-09-26

## 问题

远端用 OSC 52 写剪贴板时，App 直接忽略：opencode 的选中即复制、Codex 与 Claude Code 的复制命令、
tmux / vim 的 OSC 52 复制都进不了系统剪贴板，用户以为复制成功了，粘贴出来却是旧内容。

OSC 52 读剪贴板的请求被拒绝（不作答），远端读不到本机剪贴板。

## 现状

- 引擎（alacritty_terminal 默认的「只许复制」）接受写入请求，但上游 rsHell 的事件处理把剪贴板写入
  事件丢弃了，没有交给宿主的通道。
- 写系统剪贴板在 iOS 上不需要授权（读需要，见 20260925_iOS读剪贴板授权.md）。

## 下一步

1. 决定策略：写入是否默认允许、是否提示（如「远端已复制 N 个字符」）、是否放进连接设置；
   读取维持拒绝。
2. rsHell 补丁：剪贴板写入作为引擎事件交给宿主；hub 转成信号，Dart 写系统剪贴板。
3. 补上之后在 opencode 里选中文字、在 Codex 里复制，确认系统剪贴板收到。
