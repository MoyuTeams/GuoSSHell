# 上架前的产品与合规决定

- 状态：待决定（非阻塞，上架前必须完成）
- 记录日期：2026-09-26

## 问题

M4 把许可页、隐私清单、release 构建都准备好了，但下面这些是产品方的决定或需要开发者账号，
自动化不能替你定：

1. **bundle id、应用名、图标、签名团队**：现在是 Flutter 模板的 `com.example.guoshShell`
   与默认图标。bundle id 一旦上架就不能改，钥匙串条目与 iCloud 同步也跟它走。
2. **出口合规**：App 自带 SSH 的加密实现（russh、ring 等标准算法）。上传时要回答加密问题，
   `ITSAppUsesNonExemptEncryption` 与是否需要出口文件由你按实际情况确认后写进 Info.plist。
3. **上架定位（App Review 2.5.2 等）**：App 本身不下载、不执行代码，命令都在用户自己的服务器上
   执行。描述里讲清楚「连接你自己的服务器的 SSH 终端」，审核备注里提供一个可登录的测试服务器。
4. **隐私清单的理由**：PrivacyInfo.xcprivacy 按二进制实际引用的 API 声明了 FileTimestamp
   （C617.1）与 DiskSpace（E174.1，内置 SQLite 查询文件系统属性）。提交前按 Apple 当时的
   要求复核一遍理由代码。
5. **随签名开启的能力**：NFC 读卡（OpenPGP 卡经 NFC）、Associated Domains（安全密钥的
   RP ID，见 followup「安全密钥RP-ID与真机验收」）。

## 现状

- 隐私清单：`ios/Runner/PrivacyInfo.xcprivacy`，已加进 Runner 目标并随 App 打包。
- release 构建（不签名）通过；还没有签名的 release 在真机上跑过。
