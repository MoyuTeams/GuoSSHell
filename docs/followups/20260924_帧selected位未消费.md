# 帧里的 selected 位暂未消费

- 状态：已决定，不启用（M4，2026-09-26）
- 记录日期：2026-09-24

## 现状

选区高亮由 fork 画（`RenderTerminal._paintSelection`，数据来自引擎回显的纯坐标选区），
帧压缩格式里引擎逐格标记的 `selected` 位（`frame_codec.rs` attrs 第 5 位、Dart 侧
`Attr.selected`）无人消费。wire 格式里保留它没有成本——`same_run` 已把 selected 计入
run 边界，位宽也不变。

M4 做滚回时，Dart 侧的行号改为覆盖整个滚回（绝对行 − 最早一行），引擎回显的选区直接换算成
行号交给 fork，滚出视口的选区照样有高亮，不再需要由 `selected` 位驱动。

## 下一步

无。若以后要画 fork 做不到的选区样式（如矩形选区），再考虑改用 `selected` 位。
