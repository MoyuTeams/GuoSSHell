# 应用内接入 tailnet 隧道

- 状态：待办（非阻塞，已完成调研）
- 记录日期：2026-09-28
- Issue：[MoyuTeams/GuoSSHell#4](https://github.com/MoyuTeams/GuoSSHell/issues/4)

## 问题

手机已经开着别的 VPN 时，无法再开系统 Tailscale，也就连不上只在 tailnet 里可达的 SSH 主机。
希望 App 内自带一个 tailnet 用户态节点（不占系统 VPN / TUN），经它连接远端主机；并在连接编辑页
自动发现 tailnet 里的设备（主机名、100.x 地址、MagicDNS 名、系统、在线状态）供选择。

## 现状

尚未实现。当前阻塞在上游：`NativeSshTransport` 固定用 `TcpStream::connect` 建连，
没有注入已建立连接的入口；主机密钥按 TCP 对端 IP 记录（见 followup「主机密钥按解析后IP记录」），
经本机代理转发时对端会变成回环地址，known_hosts 会串。

调研结论：

- **方案**：自写一层很薄的 Go 包装，封装官方 tsnet，导出 C 接口供 hub 调用。
  - 连接：tsnet `Loopback()` 在回环地址起带凭据的 SOCKS5，Rust 侧连上后把流交给 russh 的
    `connect_stream`，五个平台同一条路径。
  - 发现：`LocalClient().Status()` 的对端字段已覆盖所需信息。
  - 登录：交互登录经 IPN bus 拿 `BrowseToURL` 交给 Dart 打开浏览器；控制服务器地址可配，
    兼容 Headscale。
  - 状态：自定义 `ipn.StateStore` 回调到 Rust，存进现有的各平台钥匙串。
- **未选的方案**：libtailscale 不支持 Windows，状态只能放目录，依赖的 tsnet 版本滞后；
  官方纯 Rust 实现 tailscale-rs 暂不支持 iOS / Android、没有 MagicDNS 与列出全部对端的接口。
  Rust 侧按「给目标、返回 AsyncRead + AsyncWrite」抽象，后续可换成 tailscale-rs。
- **各平台**：
  - iOS / iPadOS：Go 只能 c-archive，打成 xcframework（真机与模拟器分片，`-ldflags -w`，
    附隐私清单）；不需要 NetworkExtension。挂起后节点的 socket 被回收且不会自愈
    （[tailscale#21353](https://github.com/tailscale/tailscale/issues/21353)），需要自己恢复。
  - Android：Go 只能 c-shared，按 ABI 编 `.so`，需 16KB 页对齐；Android 11 起不能用 netlink，
    要经 `netmon.RegisterInterfaceGetter` 注入网卡列表
    （[tailscale#17311](https://github.com/tailscale/tailscale/issues/17311)）。
  - macOS：沙箱只需 `network.client` 与 `network.server`；需补 amd64 分片。
  - Windows：Go c-archive 无法与 MSVC 链接，编 c-shared DLL；系统策略会覆盖 `ControlURL`
    （[tailscale#16840](https://github.com/tailscale/tailscale/issues/16840)）。
  - Linux：无特殊限制，还可直接读系统 tailscaled 的 LocalAPI 做发现。
- **共性**：进程内只能有一份 Go 运行时；开着别的 VPN 时直连多半打不通，主要走 DERP 中继；
  每个 App 实例在 tailnet 里是一个独立节点；许可页需补 Go 依赖（含 Apache-2.0 的 gVisor）；
  每个架构的体积增量估计 15–25 MB，未实测。

## 下一步

1. 向上游提 PR：`NativeSshTransport` 支持注入已建立的连接，主机密钥按配置的主机名与端口记录；
2. 在 Linux / macOS 上做原型：Go 包装层、SOCKS5、russh 建连、设备列表，实测体积增量；
3. iOS 原型重点验证挂起恢复：只重建外层（重新绑定 UDP、重连 DERP）而不销毁用户态网络栈时，
   已有 SSH 会话能否在挂起 1 分钟、5 分钟后续上（与 followup「切后台后SSH连接断开」相关）；
4. 依次做 Android（网卡列表注入、包体）与 Windows；
5. CI 增加 Go 工具链与各平台产物，`scripts/licenses.sh` 补 Go 依赖许可；
6. 界面：设置页的 tailnet 登录、登出与控制服务器地址；连接编辑页的「从 tailnet 选择」；
   连接目录增加「经由 tailnet」字段。
