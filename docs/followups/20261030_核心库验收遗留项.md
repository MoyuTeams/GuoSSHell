## Windows 默认 shell

自动发现的 shell 位于 WindowsApps 时，本地 PTY 的默认 shell 连接测试返回
`SessionFailure::Pty`。显式选择系统 PowerShell 后，本地 PTY 测试通过。

下一步：复现自动选择与进程启动之间的失败条件，核对应用分发路径下的默认 shell
发现和启动行为。

## macOS 高编号文件描述符

PTY 就绪等待沿用原依赖的 `select` 实现；PTY 或唤醒管道的 fd 达到
`FD_SETSIZE` 时返回 `EINVAL`。宿主进程打开较多文件或连接时，合法 PTY
描述符可能因此无法继续读写。

下一步：在 macOS 验证高编号描述符下的读取、写入和关闭，评估支持该输入范围的
就绪等待实现，同时保留描述符集合的越界保护。
