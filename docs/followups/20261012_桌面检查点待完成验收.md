# 桌面检查点待完成验收

## 问题与开放边界

桌面尚未完整交付。阶段四输入、阶段五设置、Local Shell、隔离 System SSH 与最终验收仍需完成生产接线及 Windows、macOS、Linux 的构建、测试、GUI 与适用沙箱验证。正常 Prepare、Start 和真实边界所有权尚未组合验收，独立单元通过不能替代这些证据。

本分支按应用、界面和宿主可控的安全可靠性范围交付。难以在应用侧简单实现的全资源闭包与第三方内部秘密清理，按[风险评级条目](20261014_分支后深层安全加固风险.md)延后，不再作为正常生产链的前件。

新 V2 的 `Preparations::default()` 关闭准备机制；`begin`、`start` 在预算预约、解析、消费准备态或启动会话之前返回 `PolicyUnavailable`，只有测试专用构造器开启。未验收能力保持关闭，旧 Native、桌面 V1 与移动端保留原行为。这是新路径的验收守护条件，不是将正常配置、字体或 Start 永久拒绝的产品目标。

## 当前证据与限制

- **P1 单元：** 配置解码、字体来源、控制、helper、受证候选读取及网络资源根已有独立验证；实际配置图、准入前件和完整生产调用链仍须组合验收。
- **阶段四：** 正常 NativePort 的 ABI 1／19 个导出已接入原会话 actor 与 Windows 宿主，关联 Rinf 已加载的同一 hub 模块。原生 HWND、COM、TSF、文本终结、动作 claim 与退休已有组件验证，但宿主测试的 C ABI 后端仍是替身，不证明实际 Rinf 输入联证。独立 spike 的 ABI 3／11 个导出与合成 fixture 不是正常生产路径的验收证据。真实物理键、非美式布局、死键、TIP、AltGr、IME、鼠标、GUI 动作及三桌面验收仍未完成；正常生产输入 guard 保持关闭。
- **阶段五：** 独立设置表单、键位条与资源区已测试；全局字体的 RID／slot／操作确认、无 RID 写入的全应用单写者及未知结果核实、真实原生焦点、关闭期间的租约和 Rinf／SQLite 重开尚未完整接入。
- **Local：** Windows 测试专用路径的 43 项检查包含 TERM、几何、Unicode、自然退出和 8 MiB 堵写取消。完整进程与环境源界、子进程树、持久失败的有限收敛、GUI 及 macOS／Linux 沙箱尚未签收。
- **System：** 私有 helper／scope 覆盖受控 ORDER 回调、负向身份及资源检查；实际握手密钥、持久信任、强制 ASKPASS、秘密跨进程身份链、认证成功和 PTY 仍须三平台完整验收。不得直接启用继承用户配置／agent 的旧 System 路径。
- **网络：** 正常 Native 的认证、信任、PTY、读写、超时与关闭仍须实际组合验收。实验 scoped 入口及 bigint／压缩／同步候选的完整资源和秘密图延后；已有局部证据不代表全图闭合，也不要求先完成这些候选才能恢复应用生产接线。

## 下一步与签收条件

按上述守护条件继续接线，补齐输入、设置、本地与隔离 SSH、正常网络认证及最终三平台的实际证据。新能力只有在对应正常路径、应用可控资源与认证边界完成验收后才能开放，并须保持旧接口兼容。

本分支不签发 P1 `SourceClosed` 或全进程硬包络证书。正式交付仍须真实认证、正常功能、应用生命周期和三桌面实际交付路径证据；限定 fixture 和独立单元证据只能支持其已验证范围，未运行的 GUI／沙箱场景须明确标注。
