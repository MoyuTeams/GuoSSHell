# 界面与终端字体

所有平台共用同一套字体设置，界面和终端分别保存选择。

| 用途 | 内置默认字体 | 预览内容 |
|---|---|---|
| 界面 | MiSans | 中文、英文和数字 |
| 终端 | MesloLGS NF | 等宽字符、中文和终端符号 |

## 选择与恢复

1. 在设置中点击对应的「选择 TTF 文件」。无需在系统中安装字体或输入名称。
2. 检查预览，点击「应用字体」保存；「取消预览」保留原选择。
3. 使用恢复按钮可分别回到内置字体。终端建议选择等宽字体。

支持有效的 `.ttf` 文件，单个文件不超过 32 MiB。应用会保存副本，移动或删除原文件不影响已应用的字体。

## 生效范围

- 界面和终端字体切换即时生效，不关闭会话。终端会重新度量字符并更新远端行列数。
- 字号滑块同步更新预览；保存的默认字号和滚回行数用于新会话。
- 重启后恢复已保存的字体。缓存缺失、损坏或加载失败时使用内置字体并显示提示。

## 存储与许可

Rust 负责字体校验和持久化，Flutter 负责选择文件、加载及预览。预览不写入偏好；确认后按内容摘要保存副本，恢复默认或替换字体时仅清理不再引用的应用缓存。

MiSans 的来源与许可见 [来源说明](../assets/fonts/MiSans-SOURCE.md)，MesloLGS NF 许可见 [许可文件](../assets/fonts/LICENSE-MesloLGS-NF.txt)。应用许可页也提供内置字体署名与许可。
