## 审查修复

| 项目 | 最终行为与回归覆盖 |
|---|---|
| 私钥文件读取 | 读取与 UTF-8 解码错误显示在导入页；保留原输入，页面退出后不更新已释放状态 |
| 并发卡签名 | 在卡锁内取用、验证并失效缓存 PIN；多个并发请求只尝试一次失效缓存，后续请求转为询问 |
| 长组合字符 | 帧布局支持超过 15 个码点的单元格；宽 1、宽 2 及后续普通字符保持列对齐 |
| 重连时关闭窗格 | 关闭命令直接结束会话，释放命令队列、回答队列和共享上下文引用 |
| 钥匙串查询失败 | 搜索与存储错误上抛；空列表与失败分开显示，查询失败不改变同步偏好 |
| 过期交互回答 | 提示编号在整个会话内唯一；旧接受或拒绝不能回答重连产生的新提示 |
| 连接引用与密钥删除 | 保存、复制连接与密钥删除共用互斥边界；引用检查和目录提交不能跨越删除 |
| 同步迁移恢复 | 持久化迁移阶段，复制后提交目标，再清理来源；复制、读取、删除、偏好持久化失败及重启后均可恢复 |
| 连续修改设置 | 按字段提交增量，回包到达前修改另一字段不会覆盖前项 |
| 首页搜索恢复 | 返回首页时重新查询搜索框内容，接收后续删除或修改结果 |
| 嵌套分屏焦点 | 关闭活动窗格后选择同级相邻子树中的最近叶子 |
| 帧 ACK 流控 | 选区、尺寸变化、重连首帧与离线末帧共用节拍；待确认期间只合并最新画面 |
| 输入与粘贴顺序 | 键、IME 文本和粘贴共用 `InputRequest` 通道，连接期间与连上后的队列保持 FIFO |

同步请求超时不表示迁移已取消。界面会保留未确认状态及目标，允许重试；后端确认完成前
不宣称私钥仅在本机。迁移日志只包含方向、阶段与条目标识，不包含私钥或口令。
